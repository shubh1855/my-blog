Linux Capabilities

Grouped by what they control. Hover to highlight.

Identity
Critical. Direct path to root.
CAP_SETUIDSwitch to any UID. setuid(0) gives root.
CAP_SETGIDSwitch to any GID.
CAP_SETPCAPGrant or drop caps in other processes.
CAP_CHOWNChange file ownership arbitrarily.
CAP_SETFCAPSet file capabilities on binaries.
Filesystem
High. DAC does not apply.
CAP_DAC_OVERRIDEBypass all DAC checks. Read, write, execute anything.
CAP_DAC_READ_SEARCHBypass read and directory traversal. No write.
CAP_FOWNERBypass checks when owner UID does not match.
CAP_FSETIDSet SUID or SGID without being the file owner.
CAP_LINUX_IMMUTABLESet or clear immutable and append-only attributes.
CAP_MKNODCreate block and character device files.
CAP_LEASEEstablish leases on arbitrary files.
Network
Situational. Depends on configuration.
CAP_NET_BIND_SERVICEBind to ports below 1024.
CAP_NET_RAWRaw sockets. ARP spoofing and sniffing.
CAP_NET_ADMINInterfaces, routing, firewall, net namespaces.
CAP_NET_BROADCASTSocket broadcasts and multicast.
Process
High. Can target any process.
CAP_KILLSend signals to any process regardless of UID.
CAP_SYS_PTRACETrace any process. Memory injection. Container escape.
CAP_SYS_NICESet scheduling priority for any process.
CAP_SYS_RESOURCEOverride rlimits for any process.
CAP_SYS_PACCTEnable or disable process accounting.
Kernel
Critical. Arbitrary kernel access.
CAP_SYS_ADMINMount, namespace, keyring, devices. Broadest cap.
CAP_SYS_MODULELoad and unload modules. Arbitrary kernel code.
CAP_SYS_RAWIORaw I/O port access via ioperm and iopl.
CAP_SYS_BOOTReboot and kexec into a new kernel.
CAP_SYS_TIMESet the system and hardware clock.
CAP_SYS_CHROOTCall chroot() to change root directory.
CAP_SYS_LOGsyslog and kernel message ring buffer.
CAP_SYS_TTY_CONFIGTTY configuration and virtual console control.
Audit and Security
High. Can disable MAC enforcement.
CAP_AUDIT_CONTROLEnable or disable kernel audit. Change filter rules.
CAP_AUDIT_READRead the audit log via netlink socket.
CAP_AUDIT_WRITEWrite records to the kernel audit log.
CAP_MAC_ADMINOverride MAC. Bypasses Smack policy.
CAP_MAC_OVERRIDEOverride MAC entirely. Bypasses AppArmor and SELinux.
IPC and Memory
Low. No clear escalation path.
CAP_IPC_LOCKLock memory pages into RAM. Prevents swapping.
CAP_IPC_OWNERBypass IPC checks for shared memory and semaphores.
CAP_BLOCK_SUSPENDPrevent the system from entering suspend.
CAP_WAKE_ALARMTrigger wake alarms from suspend state.
Modern
Situational. Split from CAP_SYS_ADMIN in 5.8.
CAP_PERFMONPerformance monitoring. perf_event_open. Kernel 5.8.
CAP_BPFPrivileged BPF. Kernel memory reads possible. 5.8.
CAP_CHECKPOINT_RESTORECheckpoint and restore process state. Kernel 5.9.
